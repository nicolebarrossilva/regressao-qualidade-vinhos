# Trabalho Final — Análise de Regressão (ME613)

Projeto acadêmico desenvolvido na disciplina **ME613 — Análise de Regressão**, da Universidade Estadual de Campinas (UNICAMP). O trabalho investiga a relação entre propriedades físico-químicas e a qualidade de vinhos por meio de modelos de regressão linear múltipla.

## Objetivos

- Explorar e descrever as características da base de dados;
- Investigar a relação entre propriedades físico-químicas e a qualidade dos vinhos;
- Ajustar modelos de regressão linear múltipla;
- Comparar métodos de seleção de variáveis;
- Avaliar os pressupostos e o desempenho dos modelos ajustados.

## Base de dados

**Wine Quality (Red + White)**

Base de dados disponibilizada pela [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/186/wine+quality), contendo informações sobre propriedades físico-químicas e qualidade de vinhos tintos e brancos.

O conjunto utilizado no projeto reúne os dois tipos de vinho para investigar as relações entre as características analisadas e a qualidade.

## Metodologia

O desenvolvimento do trabalho envolveu:

- Análise exploratória dos dados;
- Investigação das relações entre as variáveis;
- Ajuste de modelos de regressão linear múltipla;
- Seleção de variáveis e comparação entre modelos;
- Avaliação de multicolinearidade;
- Análise de resíduos e diagnóstico dos modelos.
