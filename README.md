# Estudo da Relação entre Propriedades Físico-Químicas e Qualidade de Vinhos

Projeto acadêmico desenvolvido na disciplina de **Análise de Regressão**, com o objetivo de investigar a relação entre propriedades físico-químicas e a qualidade de vinhos utilizando técnicas de análise estatística e regressão linear múltipla.

## Objetivos

- Descrever o conjunto de dados e as variáveis analisadas;
- Investigar a distribuição da variável qualidade;
- Comparar características físico-químicas entre vinhos tintos e brancos;
- Explorar as relações entre as propriedades físico-químicas e a qualidade dos vinhos;
- Desenvolver um modelo de regressão linear múltipla;
- Avaliar e interpretar o modelo ajustado por meio de procedimentos de diagnóstico.
